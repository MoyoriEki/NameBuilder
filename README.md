# NameBuilder（ネームビルダー）

漫画のネームをペンで描くためのWebアプリ。B5・350dpi相当（2508×3541px）のページを複数持ち、縦にスクロールしながら描く。Galaxy Notes の代わりとして、Wacom MovinkPad Pro 14（Android / Chrome）で使う前提で作っている。

- 本体: `index.html`（ノービルド・ES modules）
- ペン入力の診断: `probe.html`
- 公開URL: https://moyorieki.github.io/NameBuilder/ （GitHub Pages / mainへのpushで自動デプロイ）

## 設計方針

- **ページ型**: 1ページ = 2508×3541px（B5仕上がり・350dpi）。無限キャンバス方式は採らない（それはプロットボードの役目）
- **ページ送りが標準**: 1ページずつ表示し、指で横にスワイプしてめくる（一定以上ずらすか、はじくとめくれる。足りなければ戻る）。めくる向きは右開き（漫画: 次のページは左から来る）が標準で、設定で左開きにもできる。ページ全体が見えている間だけ横スワイプがめくりになり、拡大中は普通に移動する。設定で縦スクロール表示にも切り替えられる。内部の座標はどちらのモードでも「ページ i は y=i*PITCH」のままで、送りモードは今のページにカメラを閉じ込めているだけ
- **ページ番号はメニューバーに**: ページの下には何も出さず、表示領域を広く使う。バーの ◀ 番号 ▶ でめくる・一覧を開く
- **縦バー**: 横向きタブレットでは上のバーが縦の帯（画面の左か右端）になり、道具ドックもその中に入る。ページを高さいっぱいに表示できる。設定の「メニューバー」で 自動（横長なら縦）/上/縦 を選べる。ページを置ける領域は`area()`がバーの分を除いて返し、全体表示の倍率や中央寄せはこれを基準にする
- **ペンが主役**: ペン（`pointerType: "pen"`）で描き、指はスクロール・ピンチズーム専用。これがそのままパームリジェクションになる。ペンを使っている最中と直後400msの指は掌とみなして無視する。設定で「指でも描く」にもできる
- **線はベクターで持つ**: 1ストローク = 点列（x, y, 筆圧）。undo・部分消し・拡大時のくっきり表示・フル解像度の書き出しが全部素直になる。輪郭は [perfect-freehand](https://github.com/steveruizok/perfect-freehand)（MIT, `vendor/`に同梱）で生成し、`Path2D`をストロークごとにキャッシュ
- **表示は「見えているページだけ」画像に焼く**: フル解像度のcanvasは1枚約35MBなので、全ページを持つとAndroidではすぐ落ちる。表示倍率に合わせた解像度（1/8刻み・最大等倍）でページごとのキャッシュを作り、総画素数4000万を超えたら見えていないものから捨てる。等倍を超えて拡大したときは、見えている範囲の線をベクターのまま直接描く
- **低遅延**: 描画中の線だけ重ねキャンバス（`#live`）に描く。透明なキャンバスに`desynchronized`を付けるとAndroid Chromeで透明部分が真っ黒になるので付けない。設定の「低遅延描画（実験的）」をオンにすると、不透明な`desynchronized`キャンバス（`#ink`）を描画中だけ出し、毎フレーム画面を写してから線を重ねる。`getCoalescedEvents()`で取りこぼした中間点を拾い、`getPredictedEvents()`の予測点を表示だけに使う。ペンを離したらページのキャッシュへ焼き込む
- **手ブレ補正は入力時に適用**: 平滑化済みの座標を保存する。描画側で平滑化しないので、部分消しで切った後も形が変わらない
- **筆圧の上限**: 端末とブラウザによっては強く押しても筆圧が1.0に届かない（MovinkPad Pro 14 + Firefoxの計測で最大0.55）。「筆圧の上限」（標準0.7）で割って正規化してからカーブ（ガンマ）をかける。設定画面に直近の最大筆圧を出すので、それを目安に合わせる
- **筆圧で濃さ（クリスタの「筆圧→不透明度」相当）**: ペンごとに選べる。半透明の部品を重ねると重なりが濃くなって数珠状になるので、「白と混ぜた不透明な色」で描き、合成を`darken`（濃い方を残す）にしている。同じ線の中で重なっても濃くならず、濃い線と交差しても下の線が薄くならない。濃さは32段階に丸め、段階ごとに1つの`Path2D`（円＋台形の向きを揃えて非ゼロ規則で穴を出さない）にまとめて塗る。描画中は重ねキャンバスを使わず、画面（`#view`）に増えた区間だけを描き足す（`darken`は同じ所を何度塗っても変わらないので消して描き直す必要が無く、毎フレーム描き直すと出ていたチラつきが起きない。予測点は後で消せないので使わない）。白ペンは`darken`では見えないので濃さ変化を付けない
- **濃淡の調整（ペンごと）**: 「いちばん弱いときの濃さ」`o`・「真っ黒になる強さ」`of`（この筆圧以上で濃さ100%）・「濃くなり方」`og`（カーブ。1未満で軽い力のうちから早く濃くなる）。濃さ = o + (1−o)·min(1, 筆圧/of)^og。筆圧は「筆圧の上限・カーブ」（設定）で補正した後の値。標準は o=0.15, of=0.55, og=0.7（筆圧が弱めでも黒が出る）。値はストロークごとに保存するので、後から設定を変えても描いた線は変わらない（`of`・`og` が無い古い線は of=1, og=1 として描く）。ペン設定のプレビュー欄はペンで試し描きでき、スライダーを動かすと試し描きの線にもその場で反映する
- **透明背景の書き出しは「白→透明」変換**: いったん白い紙に描いてから、各画素で a = 1 − min(R,G,B)/255、色 = (P − 255(1−a)) / a に変換する。白の上に戻せば元と同じ見た目になるので、濃さが変わる線は半透明に、白ペン（修正）は透明に抜ける
- **全画面は作品を開いている間だけ**: Webアプリからは上下のバー（ステータスバー・ナビゲーションバー）を「両方隠す/両方出す」しか選べないので、描くときだけ全画面にし、作品一覧では時計などのバーを出す。manifest は `standalone`。作品を開くタップをきっかけに `requestFullscreen({ navigationUI: 'hide' })`、一覧に戻ると解除。Androidの戻る操作などで解除されたら、次に指やペンを離したタイミングで戻す（全画面への切り替えは操作をきっかけにしかできない。押した瞬間だと描いている途中に画面の大きさが変わる）。設定「全画面」でオフにできる
- **確認・名前の入力は自前のダイアログ**: ブラウザ標準の `confirm`/`prompt` は全画面を解除してしまうので使わない（`askConfirm`・`askName`）。ページ一覧のような開いているダイアログの上に出すメニューは、そのダイアログの中に置く（モーダルの下に隠れて触れなくなるため）
- **更新時に新旧ファイルを混ぜない**: GitHub Pagesはファイルを10分キャッシュさせるので、ES modulesの一部だけ古いと読み込みに失敗してアプリ全体が動かなくなる。`index.html`の`css/app.css?v=N`・`js/app.js?v=N`と、`js/app.js`の`import … from './xxx.js?v=N'`に版番号を付け、**cssやjsを変えたら全部まとめて上げる**。Service Workerは`fetch(req, { cache: 'no-cache' })`で毎回サーバーに確認する。それでも起動に失敗したら（`window.__nbReady`が立たなければ）「最新版を読み込み直す」を出し、Service Workerとキャッシュを消して再読み込みする
- **保存はローカル（IndexedDB）**: 同一オリジン（moyorieki.github.io）の他アプリと衝突しないよう、DB名は`namebuilder`、localStorageは`nb_`接頭辞。`navigator.storage.persist()`で勝手に消されないよう要求する
- **書き出しはPNG**: 2508×3541・**350dpi**（pHYsチャンクを埋め込む）。dpiが無いとクリスタ等で72dpi扱いになり実寸がずれる。背景は白／透明を選べる。複数ページは無圧縮ZIPにまとめる。クリスタでは［ファイル］→［読み込み］→［画像］で原稿にレイヤとして置ける

## Dropbox同期（Phase 3）

[storage-bridge](https://github.com/MoyoriEki/storage-bridge) を無改造で使う（`js/cloud.js`）。ローカル（IndexedDB）が常に一次ストレージで、Dropboxはバックアップ兼ほかの端末との受け渡し。未接続・オフラインでも全機能が使える。

- **つなぎ方**: 同期ランプ（一覧の右上・編集画面のバー）をタップして開く「Dropbox同期」の「Dropbox 接続」から。プロットボード・Fileviewerと同じ storage-bridge の認証。Dropboxのアプリ設定（App Console → Settings → OAuth 2 → Redirect URIs）に **`https://moyorieki.github.io/NameBuilder/`** を登録しておくこと。`…/index.html` で開かれても起動時に `…/` へ直すので、登録はこの1つでよい
- **同期ランプ**: 緑=同期済み／黄=未同期（描いてから約20秒で自動で上がる）／青の点滅=アップロード中／水色の点滅=取り込み中／赤=エラー／灰=オフライン／白抜き=未接続。タップで詳しい状態（最後に同期した時刻・エラー内容）と「今すぐ同期」「切断」。storage-bridge の標準の接続UIは隠し、App key入力のモーダルだけ使う
- **配置**（`/NameBuilder` 以下）: `{作品ID}/doc.json`（タイトル・ページの並び）、`{作品ID}/pages/{ページID}.nbp`（線データ）、`_deleted/{作品ID}`（削除の目印）。フォルダ名は作品IDなので、名前を変えても移動は要らない
- **ページ単位で上げる**: 作品ごとに `doc.sync = { docRev, pageRev, dirtyPages, docDirty, seq }` を持ち、描いたページだけを上げる。`seq` は「上げている最中に描き足されたか」を見分ける番号で、描き足されたページは未同期のまま残って次の同期で上がる
- **線データの形式（.nbp）**: `'NBP1'` | メタJSON長 | メタJSON（`[[色, 太さ, 筆圧の効き, 濃さ|null, 点数], …]`）| Int16 x,y（1/8px単位）| Uint8 筆圧。全体を gzip して `'NBZ1'` を前に付ける（`CompressionStream`が無ければ生のまま）。ローカル（Float32）の半分以下＋圧縮
- **同期のタイミング**: 描いてから20秒後、一覧に戻ったとき、アプリが裏に回ったとき・戻ったとき、オンライン復帰、Dropbox接続時、一覧の⟳ボタン。順番は「削除の目印を処理 → 取り込み → 上げる」
- **取り込み**: `files/list_folder`（recursive）で全ファイルのrevを一度に取り、ローカルが覚えているrevと違うものだけダウンロードする。開いている作品が変わっていて、こちらに未保存の変更が無ければ、その場で開き直す
- **競合**（同じ作品を両方の端末で変えた）: **どちらも捨てない**。Dropbox側の版を「（別端末の版 日時）」という別作品として取り込み、こちらの版で上書きする
- **削除**: 削除した作品はDropboxのフォルダを消し、`_deleted/{作品ID}` を置く。ほかの端末はこの目印を見て、未同期の変更が無ければ自分の方も消す。**目印が無いのにフォルダが無い**（Dropbox上で手で消した・名前を変えた等）ときは、手元の作品を消さずに上げ直す（安全側）
- オフライン中に削除した作品は localStorage の `nb_tombstones` に覚えておき、次の同期で消す

## 操作

| 操作 | 内容 |
|---|---|
| ペン | 描く（筆圧で太さが変わる） |
| ペンのサイドボタンを押しながら | 消しゴム（設定でオフにできる） |
| ペンの消しゴム側（テールスイッチ） | 消しゴム（`button 5`／`buttons & 32`） |
| 指1本を横に | ページをめくる（送りモード・ページ全体表示中）／拡大中は移動。最後のページで「次」の方へめくると白紙のページを足してめくる（めくっている途中は点線の「＋ 新しいページ」が見える） |
| 指1本 | 縦スクロールモードではスクロール（慣性あり） |
| 指2本 | ピンチズーム・移動 |
| 2本指タップ／3本指タップ | 元に戻す／やり直す |
| ドックのペンを2回タップ | ペン設定（色・太さ・筆圧オンオフ） |
| ドックの消しゴムを2回タップ | 消しゴム設定（部分／線ごと・大きさ） |
| 右下の倍率 | タップでページ全体表示 |
| バーの ▦（またはページ番号） | ページ一覧。タップでそのページへ、各ページの ⋯ で前後に追加・複製・前後へ移動・削除。「選択」で複数ページをまとめて削除 |
| ドックの −頁 | 今のページを削除（確認あり。最後の1ページは消せない） |
| PC | マウスで描く／ホイールでページ送り（拡大中はスクロール）／Ctrl+ホイールでズーム／中ボタンドラッグで移動／Ctrl+Z・Ctrl+Shift+Z／1・2・3でペン、Eで消しゴム／←→で左右のページ、PageUp・PageDownで前後のページ |

## データモデル（version 1）

```jsonc
// IndexedDB "namebuilder"
// docs   (keyPath: id)
{ "id": "doc-…", "title": "作品名", "createdAt": "ISO", "updatedAt": "ISO",
  "w": 2508, "h": 3541, "pages": ["pg-…", "pg-…"], "lastPage": 0 }
// pages  (key: "{docId}:{pageId}")
{ "strokes": [ { "c": "#1f2328", "w": 7, "t": 0.7, "p": Float32Array[x, y, 筆圧, …] } ] }
// thumbs (key: "{docId}:{pageId}") → Blob(webp, 幅200px)
```

- `w` = 最大太さ（筆圧1.0のときの直径、page-px）、`t` = 筆圧の効き（0なら一定の太さ）、`o` = 筆圧0のときの濃さ（あるときだけ「筆圧で濃さが変わる線」。無ければ常に不透明）、`of` = 真っ黒になる筆圧、`og` = 濃さのカーブ
- ストロークは不変オブジェクトとして扱う。undo/redoは「ページのストローク配列の差し替え」で表す（1操作 = `[{pageId, before, after}]`、最大200手）
- `doc.sync` はDropbox同期の状態（上の「Dropbox同期」参照）。`lastPage` は端末ごとの表示位置でDropboxには上げない
- 見えていないページ（前後3ページより外）は、未保存でなければメモリから手放し、必要になったら読み直す
